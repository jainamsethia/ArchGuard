What it measures

  • 1

    Import boundaries

    Which modules import things they were not meant to. If your contract says the web layer must not reach into storage directly, this is where you find out that it does.

  • 2

    Coupling

    How many modules each one depends on, and how far a change would ripple. The modules everything else reaches into are the ones that are expensive to change.

  • 3

    Semantic drift

    Whether the code inside a module still belongs together. Modules accumulate unrelated responsibilities quietly; this measures how far one has wandered from a single subject.

  • 4

    Duplication

    Near-identical logic in more than one module — the kind that gets fixed in one place and stays broken in the other.

Measured, or marked unmeasured

Every number in a report comes from something ArchGuard actually ran. When a layer cannot run — no import rules declared, no history to read — the report says so, instead of scoring it zero and folding that into your grade. A missing measurement and a bad one are not the same thing.
